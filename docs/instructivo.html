Perch para Windows

Una tira flotante con una criatura pixel-art por cada sesión de Claude Code. Instructivo de instalación, uso y configuración.

Qué es

Perch no es un plugin de Claude Code: es una app aparte que se conecta a Claude Code mediante hooks en ~/.claude/settings.json. Muestra en un borde de la pantalla una criatura por sesión, animada según su estado (trabajando, esperando, terminada, dormida).

Claude Code -- hooks (curl.exe) --> agente (Bun) <-- WebSocket 127.0.0.1:7778 -- overlay (Electron) -- bandeja
claude agents --json -- sondeo -->     └ SQLite: anclajes, iconos (%APPDATA%\perch)

Todo queda en 127.0.0.1; nada sale de tu equipo.

Requisitos

  • Windows 10 u 11.
  • Bun 1.3 o superior.
  • Node.js 18 o superior.
  • Git for Windows (Claude Code ejecuta los hooks con su bash).
  • Claude Code CLI, ya funcionando en tu terminal.
winget install Oven-sh.Bun OpenJS.NodeJS.LTS Git.Git

Instalación

Opción recomendada: el asistente

  1. Instala los requisitos de arriba.
  2. Clona o copia la carpeta en cualquier ruta sin caracteres raros: 
    git clone https://github.com/harold001916/perch-windows
  3. Haz doble clic en setup.bat. El asistente, en español:
    1. comprueba Bun, Node/npm, Git, curl.exe y claude, y te da el comando exacto de lo que falte;
    2. instala las dependencias (agente y overlay, incluido Electron);
    3. pregunta tu terminal, si saltar a una sesión ya abierta en vez de abrir una copia y, para Wave, si enfocar el bloque exacto;
    4. pregunta el borde de la pantalla, el tamaño, la acción del clic y las notificaciones;
    5. ofrece instalar los hooks (con copia de seguridad), el arranque junto a Claude Code y el arranque con Windows; después inicia Perch.
  4. Reinicia las sesiones de Claude Code que ya estuvieran abiertas, para que aparezcan.
Si ejecutas setup.bat otra vez abre un menú: reconfigurar (propone tus valores actuales), estado, arrancar, detener o desactivar todo. Escribe solo %APPDATA%\perch\*.json y, si aceptas, ~/.claude/settings.json (copia: settings.json.bak-perch-*).

Si algo falta justo después de instalarlo, abre una ventana nueva para que se actualice el PATH.

Instalación manual

cd agent;   bun install
cd ..\overlay; npm i; node node_modules/electron/install.js   # npm 11 omite el postinstall de Electron
cd ..\agent;   bun src/perch.ts hooks install                 # añade los hooks a ~/.claude/settings.json
cd ..;         .\start.ps1                                    # agente (oculto) + overlay
.\startup.ps1 install                                         # opcional: arrancar en cada inicio de sesión

Instalarlo en otro PC

Copia la carpeta (puedes omitir agent\node_modules y overlay\node_modules) o clónala, y ejecuta setup.bat allí. La configuración es por equipo y no se copia: el asistente la crea.

Uso

  • La tira muestra las sesiones ancladas y las que están trabajando o esperándote. Las terminadas se quedan 5 minutos.
  • Botón +: ancla cualquier sesión conocida.
  • Hover: nombre y actividad.
  • Clic: si la sesión está viva, trae su ventana al frente; si no, la reanuda (claude --resume <id> en su carpeta).
  • Clic derecho: anclar/desanclar, personaje, color y «Abrir en terminal / VS Code / carpeta».
  • Pestaña junto a la tira: un clic la desliza fuera de la pantalla y parpadea en naranja si una sesión te necesita. Arrástrala para pegar la tira a cualquier borde de cualquier monitor.
  • Icono de bandeja: mostrar/ocultar, notificaciones, colapsar, borde, Tamaño (75-200 %), Al hacer clic abrir… (Terminal / VS Code / Carpeta) y salir.

Notificaciones

Aparecen avisos de Windows cuando una sesión pide permiso, hace una pregunta, da un error o termina un turno de al menos 10 s. Al hacer clic en el aviso se abre la sesión. Con onlyWhenUnfocused activo no se muestran mientras una terminal o editor esté al frente.

Terminales compatibles

El clic hace dos cosas distintas: enfocar la ventana de una sesión viva (se detecta sola, subiendo por el árbol de procesos de claude) y reabrir una sesión terminada (depende de terminal).

TerminalEnfocar sesión vivaReabrir sesión terminada
Windows TerminalSíSí (terminal: "wt")
cmd / PowerShellSíSí (cmd)
VS Code, Cursor, WindsurfSíVía clickAction: "code"
WaveSí, y bloque exacto con waveFocusBlockParcial: copia el comando al portapapeles y enfoca Wave
Alacritty, WezTermSíSí con custom (el asistente lo configura)
WarpSí (probado)No soportado: usa wt o cmd como respaldo
Warp. El foco de sesiones vivas está probado con una sesión real. Para reabrir una sesión terminada no hay una línea de comandos de Warp en Windows confirmada, así que no se ofrece; el asistente tampoco lo lista, así que elige wt o cmd para esos casos.

Ejemplos de settings.json

{ "terminal": "wave", "focusExisting": true }

{ "terminal": "custom",
  "command": ["alacritty","--working-directory","{cwd}","-e","claude","--resume","{id}"] }

Wave y el JWT

Con waveFocusBlock activo, los hooks reenvían a Perch el bloque y la pestaña de Wave. El JWT de Wave es una credencial: se guarda solo en la memoria del agente, nunca en SQLite, logs ni WebSocket, y se descarta al terminar la sesión. focusblock actúa solo en la pestaña actual de Wave.

Solución de problemas

  • Aparece ! en lugar de +: el overlay no llega al agente. Ejecuta .\perch.ps1 status y luego .\perch.ps1 start. Logs: %APPDATA%\perch\agent.err.log.
  • No aparecen sesiones: faltan los hooks (el estado lo indica) o la sesión se abrió antes de instalarlos; reiníciala.
  • Los hooks no hacen nada: Claude Code los ejecuta con Git Bash; comprueba que git --version funciona y que existe curl.exe.
  • El clic no abre nada o abre otra terminal: revisa terminal y focusExisting en settings.json.
  • La primera sesión tras arrancar Perch puede tardar hasta 3 s en aparecer: el agente aún no escuchaba cuando se disparó su hook y el sondeo la recoge enseguida.

Desinstalar

setup.bat → Desactivar todo, o bien .\perch.ps1 disable. Después borra la carpeta y %APPDATA%\perch. El atajo de inicio se quita con la misma opción (o con .\startup.ps1 remove). Para quitar solo los hooks: bun agent/src/perch.ts hooks uninstall.
